문서 기준일은 2026-10-12이며 아래 제출 기록은 2026-10-11 확인 범위다.
영어·한국어·일본어의 실제 Release 화면을 iPhone 6.9형(2868 × 1320)과
iPad 13형(2752 × 2064)으로 각 5장씩, 총 30장 제출했다. 순서는 전투 → 체육관 →
메인 메뉴 → 스토리 진행 → 구매 화면이며 알파 채널이 없다.

- 현재 이미지: [1.2 iPhone](1.2/iphone-6.9/) · [1.2 iPad](1.2/ipad-13/)
- 검사 기록: [캡처 요약·첨부 목록](1.2/capture-manifests/)
- 제출 근거: [앱·상품·순위표 제출 기록](../AppStoreMetadata/1.2-submission.json)
- 구매 화면 가격은 로컬 StoreKitTest의 US storefront `$2.99`다. 6개 제한된 캡처 테스트 통과·첨부 30장 확인은 실제 계정 결제·복원이나 심사 승인을 뜻하지 않는다.

현재 제출 자료와 아래 9월 홍보용 크롭 자료는 다르다. 현재 문서 정리에서 이미지를
재생성하거나 Connect에 새로 업로드하지 않았다.

## 과거 6.5형 홍보 자료 (2026-09-10)

> 당시 시안: **미니멀 리디자인**. 사용자 요청에 따라 프레임·보조 설명·태그·번호를 제거하고, 큰 이미지와 짧은 문구 하나만 남겼습니다.

## 업로드 규격

- 완성 이미지: **2688 × 1242 px**, 가로, 언어별 PNG 6장(한국어·영어·일본어)
- 색상: **8-bit RGB / sRGB / 알파 채널 없음**
- 원본: 사용자가 제공한 **2436 × 1125 px** 캡처 6장
- 사용자 승인에 따라 원본 화면을 **크롭·확대**했습니다. 종횡비는 유지하며, 캐릭터·게임 장면·스타일 선택 등 각 장의 핵심을 크게 보여줍니다.
- 일부 HUD, 메뉴, 말풍선과 화면 여백은 크롭에서 제외했습니다. 원본 인물·기능·기록을 새로 만들거나 바꾸지는 않았습니다.
- 홍보 문구는 장당 짧은 문장 하나만 사용하며, 사진의 여백 또는 상단에 크게 배치했습니다.
- 앱 코드, 공격·AI 로직, 프로젝트 설정은 이 이미지 제작 작업에서 변경하지 않았습니다.

[Apple 공식 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)에서 2026-09-10 확인:

- 6.5형 가로 허용 크기: **2688 × 1242**, **2778 × 1284**
- 이미지 형식: JPEG / JPG / PNG, **알파 채널·투명도 불가**
- 한 세트에 1~10장 등록 가능

## 영어·일본어 버전

동일한 크롭·배치·강조색을 유지하고 **추가한 홍보 문구만 번역**했습니다. 영어는 Avenir Next Condensed, 일본어는 Hiragino Sans를 사용합니다. 제공된 원본 캡처의 **게임 내부 UI는 한국어 그대로**이며, 언어별 UI까지 포함한 완전 현지화 캡처는 아닙니다.

## 디자인

- **사진 + 큰 문구 하나**. 설명문·기능 배지·숫자·장식선·반복 로고·보조 슬로건을 삭제했습니다.
- 가장자리까지 이어지는 게임 장면, 라이벌 얼굴·글러브 클로즈업, 실제 스타일 선택 화면을 사용합니다.
- 언어별 굵은 글자와 청색·적색·금색의 단일 강조, 체육관은 실제 바닥 위에 검정 글자만 사용합니다.
- 별도의 이미지 프레임·카드·그라데이션·가짜 기기·임의 수상/순위/평점·가격 홍보 없음
- 강화학습 런타임, 온라인 대전 등 구현되지 않은 기능을 홍보하지 않음

## 사용 안내

1. App Store Connect의 해당 앱 버전에서 한국어·영어(미국)·일본어 중 해당 스크린샷 영역을 엽니다.
2. iPhone **6.5형** 슬롯에 완성 PNG를 번호 순서대로 등록합니다.
3. 전체 미리보기는 검토용이며 스토어 업로드용 이미지가 아닙니다.
4. 뒤쪽 5·6번은 링 소개·경기 도입 장면입니다. 실제 조작 화면을 보여주는 1~4번을 앞에 유지하는 구성을 권장합니다.
