# RIVAL Media

실제 게임 화면과 완성 홍보물을 탐색하는 공개 미디어 인덱스입니다. 원본 녹화·라이선스 제한 음원·빌드 산출물은 공개 미디어와 분리합니다.

스토리 장면은 2026-10-12 기준 출시 전 콘텐츠입니다. App Store에서 이용 가능한 버전과 현재 소스·심사 제출 화면을 동일하게 취급하지 않습니다. 홍보 영상의 일부 장면은 원본 녹화를 확대했으므로 전체가 네이티브 4K라는 뜻이 아닙니다.
