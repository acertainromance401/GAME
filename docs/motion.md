# Orthodox 복싱 공격 동작 모션 설명 프롬프트

오소독스(Orthodox) 스탠스를 기준으로 실제 복싱에서 사용되는 공격 동작의 **신체 움직임과 모션을 매우 디테일하게 설명하라.**

대상 공격은 다음 8가지로 제한한다.

1. 왼손 잽 (Left Jab)
2. 오른손 크로스 (Right Cross)
3. 왼손 바디샷 (Left Body Shot)
4. 오른손 바디샷 (Right Body Shot)
5. 왼손 훅 (Left Hook)
6. 오른손 훅 (Right Hook)
7. 왼손 어퍼컷 (Left Uppercut)
8. 오른손 어퍼컷 (Right Uppercut)

## 기본 자세

모든 동작은 오소독스 스탠스에서 시작한다.

* 왼발이 앞
* 오른발이 뒤
* 왼손이 리드 핸드
* 오른손이 리어 핸드
* 양발은 안정적인 간격을 유지
* 무릎은 자연스럽게 굽힌다.
* 체중은 양발에 안정적으로 분배한다.
* 턱은 당긴다.
* 왼손과 오른손은 기본 가드 위치에 둔다.
* 공격하지 않는 손은 가능한 한 얼굴과 턱을 보호한다.

---

# 각 공격의 설명 방법

각 공격마다 반드시 다음 항목을 순서대로 설명한다.

### 1. 시작 자세

공격 직전의 손, 팔꿈치, 어깨, 머리, 몸통, 골반, 무릎, 발의 위치를 설명한다.

### 2. 동작 시작

어떤 신체 부위가 가장 먼저 움직이는지 설명한다.

### 3. 하체 움직임

발, 발목, 무릎, 고관절의 움직임을 구체적으로 설명한다.

### 4. 골반 움직임

골반의 회전 방향과 이동 방향을 설명한다.

### 5. 몸통 움직임

허리와 상체의 회전, 기울기, 상승 또는 하강을 설명한다.

### 6. 어깨 움직임

공격하는 쪽 어깨와 반대쪽 어깨의 움직임을 설명한다.

### 7. 팔꿈치 움직임

팔꿈치의 굽힘/펴짐과 이동 방향을 설명한다.

### 8. 손목과 주먹

주먹의 방향, 손목의 위치, 회전 여부를 설명한다.

### 9. 전체 궤적

주먹이 시작 위치에서 목표 위치까지 어떤 궤적으로 움직이는지 설명한다.

예:

* 직선
* 반원
* 아래에서 위
* 사선
* 측면

### 10. 체중 이동

공격 과정에서 체중이 어느 발로 이동하는지 설명한다.

### 11. 충격 직전과 충격 순간

충격 직전에 몸의 어느 부분이 안정되는지, 충격 순간 어떤 자세가 만들어지는지 설명한다.

### 12. 회수 동작

공격 이후 손과 몸이 어떻게 기본 가드 자세로 돌아오는지 설명한다.

### 13. 동작의 핵심

해당 공격을 다른 공격과 구분하는 가장 중요한 신체적 특징을 설명한다.

---

# 1. 왼손 잽 (Left Jab)

오소독스에서 앞손인 왼손을 사용한다.

* 왼손은 가드 위치에서 시작한다.
* 왼팔을 목표 방향으로 직선에 가깝게 뻗는다.
* 왼쪽 어깨가 앞으로 이동하면서 턱을 보호하는 역할도 한다.
* 오른손은 턱 옆에서 방어를 유지한다.
* 필요에 따라 앞발의 미세한 전진이 동반될 수 있다.
* 주먹은 목표를 향해 가장 짧은 경로로 이동한다.
* 공격 직후 왼손을 빠르게 가드 위치로 회수한다.
* 큰 골반 회전이나 과도한 체중 이동은 사용하지 않는다.
* 잽의 핵심은 짧고 직선적이며 빠른 움직임이다.

**전체 모션:**

`가드 → 왼팔 전진 → 왼쪽 어깨 전진 → 주먹 전진 → 타격 → 즉시 회수 → 가드`

---

# 2. 오른손 크로스 (Right Cross)

오소독스의 뒷손인 오른손을 사용하는 직선 공격이다.

* 오른손은 오른쪽 턱 옆에서 시작한다.
* 오른발을 중심으로 하체를 회전시킨다.
* 오른발 뒤꿈치가 들리면서 발이 회전할 수 있다.
* 오른쪽 무릎과 고관절이 회전에 참여한다.
* 골반이 회전한다.
* 골반의 회전을 몸통이 이어받는다.
* 오른쪽 어깨가 앞으로 이동한다.
* 오른팔은 목표를 향해 직선으로 뻗는다.
* 왼손은 얼굴을 보호한다.
* 공격 이후 오른손을 빠르게 가드로 회수한다.

**힘의 연결:**

`오른발 → 무릎/고관절 → 골반 → 몸통 → 오른쪽 어깨 → 팔 → 주먹`

**전체 모션:**

`가드 → 하체 회전 → 골반 회전 → 몸통 회전 → 오른쪽 어깨 전진 → 오른팔 신전 → 타격 → 회수`

---

# 3. 왼손 바디샷 (Left Body Shot)

오소독스의 왼손으로 상대의 몸통을 공격한다.

* 얼굴을 공격할 때보다 몸의 높이를 낮춘다.
* 무릎과 고관절을 이용하여 몸을 낮춘다.
* 상체를 적절한 방향으로 기울인다.
* 왼쪽 어깨와 골반이 함께 움직인다.
* 왼팔은 얼굴 공격보다 짧고 굽어진 형태로 움직인다.
* 주먹은 상대의 몸통을 향한다.
* 오른손은 얼굴을 보호한다.
* 공격 후 다시 몸을 세우면서 왼손을 가드로 회수한다.

**핵심 모션:**

`몸을 낮춤 → 측면 이동 → 골반/몸통 회전 → 왼손 전진 → 타격 → 몸을 회복 → 가드`

---

# 4. 오른손 바디샷 (Right Body Shot)

오소독스의 오른손으로 상대의 몸통을 공격한다.

* 오른손 가드에서 시작한다.
* 무릎과 고관절을 이용해 몸을 낮춘다.
* 상체를 공격 방향에 맞게 이동시킨다.
* 오른쪽 골반과 몸통을 회전시킨다.
* 오른쪽 어깨가 공격 방향으로 이동한다.
* 오른팔은 적절하게 굽힌 상태에서 몸통을 향해 움직인다.
* 왼손은 얼굴을 보호한다.
* 타격 후 오른손을 회수하고 가드 자세로 돌아온다.

**전체 모션:**

`가드 → 몸을 낮춤 → 골반 회전 → 몸통 회전 → 오른쪽 어깨 이동 → 오른손 전진 → 타격 → 회수`

---

# 5. 왼손 훅 (Left Hook)

왼손을 사용하여 측면에서 반원 형태로 공격한다.

* 왼손 가드에서 시작한다.
* 왼쪽 무릎과 고관절을 이용해 회전을 시작한다.
* 왼발을 축으로 몸통이 회전한다.
* 골반의 회전이 몸통으로 전달된다.
* 왼쪽 어깨가 회전한다.
* 팔꿈치는 굽힌 상태를 유지한다.
* 주먹은 직선이 아니라 반원 형태의 궤적을 그린다.
* 주먹은 상대의 측면 턱 또는 머리 방향으로 이동한다.
* 오른손은 얼굴을 보호한다.
* 타격 후 왼손을 가드 위치로 회수한다.

**핵심 모션:**

`왼발 축 → 골반 회전 → 몸통 회전 → 어깨 회전 → 팔꿈치 유지 → 주먹의 반원 궤적 → 타격 → 회수`

팔을 단순히 휘두르는 것이 아니라 **몸통 회전으로 팔을 이동시키는 동작**으로 설명한다.

---

# 6. 오른손 훅 (Right Hook)

오른손을 사용하여 측면에서 반원 형태로 공격한다.

* 오른손 가드에서 시작한다.
* 오른쪽 하체를 이용해 회전을 시작한다.
* 오른발을 축으로 하체와 골반이 회전한다.
* 몸통이 골반의 회전을 이어받는다.
* 오른쪽 어깨가 회전한다.
* 오른팔꿈치는 굽힌 상태를 유지한다.
* 오른손 주먹이 반원 형태의 궤적으로 이동한다.
* 상대의 측면 턱이나 머리 방향으로 주먹을 이동시킨다.
* 왼손은 얼굴을 보호한다.
* 타격 직후 오른손을 가드로 회수한다.

**핵심 모션:**

`오른발 축 → 골반 회전 → 몸통 회전 → 어깨 회전 → 주먹 반원 이동 → 타격 → 회수`

---

# 7. 왼손 어퍼컷 (Left Uppercut)

왼손으로 아래에서 위쪽으로 상대의 턱을 공격한다.

* 왼손 가드에서 시작한다.
* 무릎과 고관절을 굽혀 몸을 낮춘다.
* 상체가 낮아진다.
* 왼쪽 하체로 지면을 밀어내면서 몸이 다시 상승한다.
* 골반과 몸통이 상승하면서 회전한다.
* 왼쪽 어깨가 상승한다.
* 왼팔은 과도하게 크게 휘두르지 않는다.
* 주먹은 아래에서 위로 짧은 궤적으로 이동한다.
* 상대의 턱 아래쪽을 향한다.
* 오른손은 얼굴을 보호한다.
* 타격 후 왼손을 가드로 회수한다.

**핵심 모션:**

`몸을 낮춤 → 하체 추진 → 골반 상승/회전 → 몸통 상승 → 어깨 상승 → 주먹 상승 → 타격 → 회수`

---

# 8. 오른손 어퍼컷 (Right Uppercut)

오른손으로 아래에서 위쪽으로 상대의 턱을 공격한다.

* 오른손 가드에서 시작한다.
* 무릎과 고관절을 굽혀 몸을 낮춘다.
* 오른쪽 하체로 지면을 밀어낸다.
* 오른쪽 골반이 상승하면서 회전한다.
* 몸통과 오른쪽 어깨가 상승한다.
* 오른팔은 짧은 궤적으로 아래에서 위로 이동한다.
* 주먹은 상대의 턱 아래쪽을 향한다.
* 왼손은 얼굴을 보호한다.
* 타격 직후 오른손을 가드로 회수한다.

**핵심 모션:**

`몸을 낮춤 → 오른쪽 하체 추진 → 골반 상승/회전 → 몸통 상승 → 어깨 상승 → 주먹 상승 → 타격 → 회수`

---

# 동작별 핵심적인 차이

### 잽

직선 + 빠른 전진 + 최소한의 회전

### 크로스

직선 + 강한 하체/골반/몸통 회전

### 바디샷

몸의 하강 + 측면 이동 + 몸통 회전

### 훅

몸통 회전 + 주먹의 반원 궤적

### 어퍼컷

몸의 하강 → 상승 + 주먹의 아래→위 궤적

모든 동작은 **팔만 움직이는 동작으로 표현하지 않는다.**
발, 무릎, 고관절, 골반, 몸통, 어깨, 팔꿈치, 손목, 주먹이 연결되어 하나의 연속적인 전신 움직임을 만드는 것으로 설명한다.

또한 각 공격은 **준비 → 가속 → 공격 궤적 → 타격 순간 → 감속 → 회수 → 가드 복귀**의 전체 모션으로 설명한다.

# 키에 대한 설명

Q = Left Duck
W = Head Guard
E = Right Duck

A = Left Jab
S = Backstep / Layback
D = Right Cross

A       = Left Jab
D       = Right Cross

Q + A   = Left Body
E + D   = Right Body

W + A   = Left Uppercut
W + D   = Right Uppercut

Q + D   = Right Hook
E + A   = Left Hook

Q + 같은 쪽 손(A)
→ 왼쪽으로 몸을 낮추면서 왼손 바디

E + 같은 쪽 손(D)
→ 오른쪽으로 몸을 낮추면서 오른손 바디

Q + 반대쪽 손(D)
→ 왼쪽으로 피하면서 오른손 훅

E + 반대쪽 손(A)
→ 오른쪽으로 피하면서 왼손 훅

W + A/D
→ 머리 가드 자세에서 아래에서 위로 어퍼컷
