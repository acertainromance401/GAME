# 보안 경계와 공개 자료

기준: 2026-10-12 · RIVAL 1.2(6) 소스와 저장소 설정. 보안이 완료됐다는 인증이 아니라 공개 가능한 자료, 실행 권한과 남은 위험을 구분하는 문서입니다.

## 자료 분류

| 분류 | 자료 | 취급 |
| --- | --- | --- |
| 공개 구현 | iOS 소스, 테스트, 웹·레거시, Blender 제작 원본 | 소스 공개와 실행·배포 권한은 별개. 코드를 검토한 뒤 실행 |
| 공개 메타데이터 | Bundle·Team·상품·앱 ID, 개인정보 선언, 제출 상태 | 인증 비밀이 아님. 심사 기록은 그 날짜의 사실만 의미 |
| 공개 미디어 | 실제 스크린샷, 완성 예고편, 문서용 파생 이미지 | [미디어 안내](../media/README.md)에서 버전·캡처 조건·라이선스 구분 |
| 로컬 전용 | 원본 녹화, 제한된 음악 원본, 빌드·아카이브, 개인 IDE 설정 | Git 제외. 공개 다운로드나 문서 필수 링크로 사용하지 않음 |
| 인증 비밀 | `.env`, `.p8`, `.p12`, `.pfx`, 개인 키·프로비저닝 프로파일, 토큰 | Git 제외, 별도 안전한 저장소 사용. 노출 시 폐기·회전 |

[.gitignore](../../.gitignore)는 예방 규칙이며 이미 추적된 파일·과거 이력에는 소급 적용되지 않습니다. `.env.example`과 `.env.template`은 공유 가능한 예제일 뿐 실제 자격 증명을 넣지 않습니다. 외부 음원 라이선스와 개인정보는 일반 소스 라이선스로 덮을 수 없습니다.

## 배포와 공급망

- [Pages workflow](../../.github/workflows/deploy-pages.yml)는 `main`만 허용하고 업로드·배포 작업을 분리합니다. 쓰기·OIDC 권한은 배포 작업에만 부여하며 Checkout은 자격 증명을 남기지 않습니다.
- GitHub Actions와 선택적 FTXUI는 확인한 버전의 전체 커밋 SHA로 고정합니다. SHA 고정은 자동 태그 변경을 막을 뿐 의존성 자체의 무해함을 보장하지 않습니다. 업데이트 때 upstream 변경·공지를 검토하고 버전과 SHA를 함께 확인합니다.
- GitHub의 `github-pages` 환경에서도 배포 허용 브랜치와 필요한 보호 규칙을 설정해야 합니다. 실제 서비스 설정·배포 성공은 이번 로컬 검사 범위가 아닙니다.
- Pages 산출물은 `pixel-boxing/`만 업로드합니다. 앱 아카이브·음원·제출 기록·저장소 전체를 웹에 배포하지 않습니다.

## 개발 도구

제작·홍보 스크립트는 파일 생성·덮어쓰기와 로컬 도구 실행이 가능합니다. Git 제외와 별개로 코드를 읽고 입력·출력 경로를 확인해야 합니다. [배포 전 점검](../../ios-pixel-boxing/scripts/pre_release_check.sh)은 Xcode 프로젝트를 재생성하고 빌드하므로 단순한 읽기 전용 검사로 실행하지 않습니다.

[C++ 터미널 도우미](../../scripts/open_game_terminal.sh)는 경로를 AppleScript 인자로 전달하고 셸 인용을 적용합니다. 경로 문자열이 실행 코드에 직접 삽입되지 않으며, 이미 빌드한 로컬 실행 파일을 Terminal에서 실행하는 용도입니다.

## 앱 권한과 데이터

| 경계 | 확인한 구현 | 남은 한계 |
| --- | --- | --- |
| Story 구매 | [StoreKit](../../ios-pixel-boxing/PixelBoxingIOS/StoryPurchaseStore.swift)의 검증된 대상 비소모성 거래와 취소·업그레이드 확인 | 실제 Sandbox/Production 구매·복원·권한 취소는 별도 검증 |
| 기존 유료 고객 | 검증된 Production AppTransaction·Bundle ID·원본 빌드 `1...4` | 무료 가격 전환·구버전 배포 시차에 따른 자격 경계 미해결. [출시 체크리스트](../release/RELEASE_READINESS_CHECKLIST.md)에서 관리 |
| 개발 미리보기 | [StoryMode](../../ios-pixel-boxing/PixelBoxingIOS/StoryMode.swift)의 DEBUG 전용 우회, 별도 저장소·비영속 경기. Release는 비활성화 | 실구매 확인 때 DEBUG 체험을 꺼야 함. Debug 결과를 배포 권한 검증으로 취급하지 않음 |
| 로컬 기록 | 습관·진행·장비는 UserDefaults에 보관 | 신뢰 가능한 서버 증명이나 암호화 금고가 아님. 변조된 클라이언트의 기록까지 증명하지 않음 |
| Game Center | [관리자](../../ios-pixel-boxing/PixelBoxingIOS/GameCenterManager.swift)의 인증·조회·점수 제출 | 순위표는 서버 검증형 안티치트가 아님. 실계정 제출·재접속 확인 필요 |
| 개인정보 | [공개 정책 원본](../../pixel-boxing/privacy/index.html)의 로컬 데이터·Apple 거래/랭킹·지원 이메일 설명 | 실제 Pages 반영과 Connect 개인정보 응답의 최종 일치 확인 필요 |

현재 iOS AI는 외부 AI API를 사용하지 않습니다. 선택적 Game Center와 StoreKit은 네트워크를 사용하므로 앱 전체가 네트워크를 사용하지 않는다고 설명하지 않습니다.

## 점검 한계와 대응

정리 전 추적 텍스트의 대표 키·토큰 패턴에서 노출 후보를 발견하지 못했습니다. 과거 Git 이력, 바이너리 내부, 미디어 메타데이터, 외부 서비스 설정은 종합 감사하지 않았으며 미발견을 안전 보증으로 해석하지 않습니다.

실제 문제 발견 시 [비공개 제보](../../SECURITY.md)를 이용합니다. 비밀값 노출은 문서에서 숨기거나 파일을 옮기는 것으로 해결되지 않습니다. 자격 증명 폐기·회전, 사용 로그 확인, 영향받는 릴리스·서비스 제한과 이력 정리를 별도로 수행해야 합니다.
