# Pixel Boxing Prototype

A self-contained browser boxing game prototype.

## Run

Open `index.html` directly in a browser, or serve the folder with a static server.

Example:

```bash
cd pixel-boxing
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000`.

## Controls

- Move: Arrow keys or WASD
- Jab: `Z`
- Cross: `X`
- Hook: `C`
- Guard: Hold `V`
- Dodge: `Space`
- Restart: `R`

## Notes

This prototype is intentionally dependency-free so it can be shared on GitHub and played on Windows, macOS, and Linux without extra setup.
