# Legacy Implementations

현재 메인 제품은 [RIVAL iOS](../ios-pixel-boxing/README.md)입니다. 이 폴더는 전투 규칙·입력·화면 표현을 검증한 이전 구현을 보존하며 현행 iOS 기능이나 배포 상태를 나타내지 않습니다.

| 구현 | 역할 | 진입점 |
| --- | --- | --- |
| [terminal-cpp](terminal-cpp) | C++20 터미널 전투·라운드·저장·패턴 모델 | [빌드 안내](terminal-cpp/README.md) |
| [python](python) | Python/Tkinter 탑다운 전투와 headless 코어 | [실행·조작·테스트 안내](python/README.md) |
| [godot](godot) | Godot 4 이식 가능성 실험, 개발 보류 | [project.godot](godot/project.godot) |

[웹 프로토타입](../pixel-boxing/README.md)은 공개 지원·개인정보 페이지와 같은 Pages 산출물을 사용하므로 기존 경로를 유지합니다. 과거 설계 자료는 [문서 인덱스](../docs/README.md)의 레거시 항목에서 확인합니다.

과거 테스트·성능 수치는 그 당시 소스의 기록입니다. 현재 iOS 앱의 보안 지원·회귀 검증과 혼동하지 않습니다.
