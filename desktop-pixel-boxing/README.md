# Pixel Boxing Desktop Prototype

A local desktop boxing game prototype that runs as a program, not in the browser.

## Run

```bash
python3 pixel_boxing_desktop.py
```

## Controls

- Move: `WASD` or Arrow Keys
- Jab: `J`
- Cross: `K`
- Hook: `L`
- Guard: Hold `V`
- Dodge: `Space`
- Restart: `R`

## Notes

- This version is dependency-free and uses Python's built-in `tkinter`.
- It is ready to be packaged later for Windows, macOS, and Linux.
